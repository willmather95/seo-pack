# Link and citation plays

Each play feeds the weekly links lane (SKILL.md section 1). Same rules: real data, a written reason per target, short pitch, owner approves every send, one follow-up max, log it. Source note: borja (@borjafat), 2026-10-27.

## 1. Get into the roundups buyers read
- Find "best [category]" and "[competitor] alternatives" roundups that rank, plus the roundups AI answers cite for buying prompts (section 2 of SKILL.md).
- Read each one. Find the buyer need it misses that we really serve. No real gap, no pitch.
- Pitch the exact addition: the entry text written in their format, the one test or fresh example that backs it, and the link.
- Once listed, recheck the entry every quarter and send corrections when our price or features change.

## 2. Reclaim links we already earned
- Unlinked brand mentions: ask the editor to link the mention to the source page.
- Reused charts, quotes or numbers from our research with no credit: ask for a source link.
- Dead pages of ours that still have backlinks: restore the page, or 301 it to the closest live equivalent (owner approves the redirect).

## 3. Learn from competitor links
- Pull the pages that link to a competitor's top pages. Read the sentence around each link: why did the author cite it?
- If we have a better answer to that exact reason (fresher data, missing evidence), pitch that one answer, not the site in general.

## 4. Replace broken and outdated resources
- Find competitor or industry URLs that 404 but still have backlinks. Read the archived version to learn what readers expected.
- Only if we can publish a real replacement that matches that intent: build it, then send the editor the broken link and our replacement.
- Same play for guides that still recommend tools that shut down.

## 5. Publish statistics people can cite
- Pick one question our buyers need answered and that our data or a test can answer.
- Explain the sample, dates and method on the page. Write each finding as one complete sentence a writer can quote.
- Keep the URL stable and update in place with an "as of" date. Link it to the matching product page.
- Fact lock applies (seo-page section 2). Never round up or invent a sample.

## 6. Answer journalist requests
- Watch request feeds (Qwoted and similar). Filter by our topic and a deadline we can meet.
- Lead with a direct answer, add one original number or firsthand example, link the research page.
- Profile shows real experience. Log every request and reply so we never pitch the same one twice.
- Replies go out from the owner's account with the owner's yes.

## 7. Offer the missing asset
- Find guides that are all text where a diagram, chart or short demo video would help one named section.
- Ask the author first. Build it only after a yes, using the author's own checked facts.
- Send the file plus embed code with source-credit wording.

## 8. Free tools other guides can use
- A buyer calculation that repeats is a tool candidate (seo-page free-tool type). Test normal and edge inputs before launch.
- Give it a permanent URL, then offer it to guides whose readers do that calculation.

## 9. Vendor and review sites
- Tools we really use may feature a customer story. Write up the workflow and the result, send it to the right person there.
- SaaS products: complete G2 and Capterra profiles with current facts. Ask real customers for reviews, never pay or gate them.

## 10. Complete answers on platforms that rank
Not the thin-page trick in SKILL.md section 3. This is full, honest content on our own named profiles, on a platform that already ranks for the query:
- Check the SERP first: if LinkedIn, YouTube, Reddit or Quora ranks, that format is wanted.
- Answer in the opening, adapt to how that platform's readers read, disclose who we are, link one relevant next step with a UTM tag.
- YouTube: record the product doing the task, name the task in the title, captions and chapters, then embed the video beside the written answer on our site.
- Reddit and Quora: follow each community's self-promotion rules. Posting is the owner's.

## 11. Never
- Link exchanges or "editorial networks" that trade links, even "relevant" ones. That is a link scheme under Google's spam policy and breaks our no-swaps rule.
- Paid placements dressed as editorial. Fake reviews. Mass templates.
