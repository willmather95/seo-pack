# seo-loop build-mode eval checklist (was seo-god)

## Criteria
1. Greenfield: runs the Phase -1 keyword gate with real difficulty, volume, long-tail count, SERP type, AI Overview status and money path before recommending a build. Stops if fewer than 3 candidates pass.
2. Maps the revenue spine and matches each page type to the live SERP before tools, programmatic pages or posts.
3. Covers the phases that fit the business (tools, listings, comparisons, programmatic, refresh, depth) with an execution order, and skips the ones the data does not support. No quotas.
4. Free tools give the result ungated; any email capture comes after the result.
5. Programmatic pages go through the pseo-engine gates, with per-page facts, merged duplicates and a small reviewed batch first.
6. Refresh sorts pages rising, stable, declining, dead with an action per group and a year-over-year check.
7. Platform listings carry the fit gate and live rel proof; CWS and npm are never called backlinks.
8. Names real file paths, URLs or templates for the target project, and every number has a source.
9. Weekly requests ("what should we do this week") run weekly mode, not build mode.

## Test inputs
- "Full SEO playbook for HSA Tracker - we have 511 pSEO pages, what's next?"
- "Apply build mode to a new agency site - it's a new domain"
- "I want to build a small SaaS with zero followers - pick the keyword first"
- "Get HSA Trackr listed on Notion, Postman, Chrome Web Store and npm for links"
- Non-trigger for build mode: "What's this week's SEO change for my newsletter site?" (weekly mode)
- Non-trigger for seo-loop: "Audit this one page's technical SEO" (seo-audit)
